# Горячие клавиши: Millénaire, мир тысячного года

Изменить любую клавишу можно в меню «Настройки → Управление → Привязка клавиш». Строка поиска наверху находит действие по названию.

## Основное
| Клавиша | Действие |
|---|---|
| W A S D, Пробел, Shift, Ctrl | Движение, прыжок, присесть, бег |
| ЛКМ / ПКМ | Удар / использовать. Со щитом в левой руке ПКМ блокирует |
| E | Инвентарь |
| **Ё** | **Книга квестов** |
| **P** | **Деревья навыков (прокачка персонажа)** |
| **C** | **Зум** (колёсико мыши во время зума меняет приближение) |
| F | Предмет во вторую руку |
| Q | Выбросить предмет |
| Колёсико (нажатие) | Взять блок под прицелом |
| T, / | Чат, команды |
| L | Достижения |
| F5 | Вид от первого или третьего лица |
| F2 / F11 | Скриншот / полный экран |

## Millénaire
| Клавиша | Действие |
|---|---|
| ПКМ по жителю | Разговор: торговля, вождь, наём, задания |
| V | Список известных деревень |
| N | Инфопанель деревни |
| J | Путевая книга |
| . (точка) | Позиция эскорта (наёмники) |

## Карта и подсказки
| Клавиша | Действие |
|---|---|
| M | Карта FTB Chunks |
| = / − | Масштаб миникарты |
| Shift (наведя на предмет) | Подробная подсказка |
| Num 0–5 | Jade: настройки, показ подсказки, жидкости, рецепты, применения |

## В книге квестов
| Клавиша | Действие |
|---|---|
| Tab / Shift+Tab | Следующая / предыдущая глава |
| Пробел | Вернуть вид в центр |
| Ctrl+F | Поиск |
| Стрелки, = / − / 0 | Перемещение и масштаб |

## JEI (рецепты, в инвентаре)
| Клавиша | Действие |
|---|---|
| R / U | Как сделать предмет / где он используется |
| A | Добавить в закладки |
| Ctrl+F / Ctrl+O | Поиск / скрыть панель JEI |
| Backspace | Назад к прошлому рецепту |

## Транспорт
| Клавиша | Действие |
|---|---|
| R | Паруса корабля (Small Ships) / действие телеги (AstikorCarts) |
| Z | Притормозить телегу |
| H / G | SWEM: аллюр быстрее / медленнее |
| ; | SWEM: седельная сумка и скатка |
| Alt | SWEM: фиксация камеры / свободный обзор |

## Прочее
| Клавиша | Действие |
|---|---|
| B | Открыть рюкзак |
| X | Сменить инструмент в рюкзаке |
| I | Колчан Spartan Weaponry |
| U | История смертей (Corpse) |
| Y | Камера через другое плечо |
| ← → ↑ ↓, PgUp / PgDn | Сдвиг камеры через плечо |
| K | Шейдеры вкл/выкл |
| O | Выбор шейдерпака |
| F6 | Перезагрузить шейдеры |
| F10 | Настройки звука шагов |
| Shift + ПКМ пустой рукой | Поднять сундук или животное (Carry On) |
| F4 | Режим съёмки Picture Mode: свободная камера, без интерфейса |
| F7 | Скрыть или показать сами рамки у рамок с предметами |
| F8 | Осмотреть предмет в руке (Punchy) |
| WASD в открытом инвентаре | Ходить, не закрывая инвентарь или сундук (InvMove) |

## Что отключено
Эти клавиши сняты, потому что пересекались с другими или не нужны в выживании:
- колчан Supplementaries (колчан Spartan остаётся на I);
- слоты Curios (для них есть кнопка в инвентаре);
- полёт, крылья, ледяная поступь и «танковое» управление SWEM (полёт в 1.21.1 не работает);
- креативные панели инструментов (C и X);
- пушка Small Ships;
- редактор анимаций Punchy (стрелки, R, Delete, F6, F7, цифровой блок): инструмент для авторов анимаций, в игре не нужен.
